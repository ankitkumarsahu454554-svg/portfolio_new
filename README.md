## ✦ Key Projects

1. **Rare Disease Prediction AI System**
   * *Problem:* Diagnosing rare genetic disorders from complex, overlapping symptom profiles is slow and prone to errors.
   * *Solution:* Built a deep learning pipeline leveraging Human Phenotype Ontology (HPO) representations to rank candidate diseases, evaluated with Top-K accuracy and Mean Reciprocal Rank (MRR).
   * *Tech:* Python, PyTorch, HPO Ontology, Scikit-learn, Pandas.

2. **MediKiosk — Multilingual Clinical Intake & OCR**
   * *Problem:* Hospital outpatient departments experience severe congestion, registration delays, and language barriers.
   * *Solution:* Full-stack automated medical kiosk enabling voice-based multilingual intake, optical character recognition (OCR) of prescriptions, and real-time physician triage scoring.
   * *Tech:* React, FastAPI, Python, PostgreSQL, OCR, Tailwind CSS.

3. **SecureWipe Enterprise Data Sanitization**
   * *Problem:* Storage drives decommissioned without cryptographic data sanitization risk data leakage.
   * *Solution:* Storage media sanitization platform complying with NIST SP 800-88 Clear and Purge standards, featuring native multi-device wiping and tamper-evident audit logs.
   * *Tech:* Go, Rust, Electron, TypeScript.
